# 2. Nosso Produto

## 2.1 Visão do Produto

Enquanto o paradigma atual de plataformas gigantes de turismo (Booking, Decolar, Kayak) exige que o usuário já saiba para onde quer ir para então aplicar filtros de preço, o Limity adota a inovadora abordagem **budget-first**: o usuário informa "tenho R$ 2.000 e quero praia" e o sistema responde com os destinos viáveis (voo + hotel) para aquele orçamento naquele momento. Em vez de competir para vender a passagem para um destino que o usuário já escolheu, o Limity elimina a frustração do planejamento financeiro e ajuda o usuário a descobrir para onde ele consegue ir.

## 2.2 Nosso Produto

| **O que somos (Identidade)** | **O que entregamos (Ação)** |
| --- | --- |
| **É:** Um aplicativo focado no orçamento (Budget-first), B2C, voltado para descoberta e viabilização de turismo. | **Faz:** Realiza busca reversa: filtra destinos por orçamento, cruza dados de APIs de voos/hospedagem e sugere pacotes viáveis. |
| **Não é:** Uma agência de turismo tradicional, um ERP de gestão financeira pessoal, ou uma plataforma de turismo de luxo sob medida. | **Não faz (MVP):** Reserva e checkout direto no app (o Limity atua como redirecionador para os parceiros), emissão de vistos, ou roteiros hiper-personalizados dia a dia. |

## 2.3 Modelo de Negócios (Monetização)

Para garantir a sustentabilidade do projeto, o Limity opera sob o modelo de **Metabusca com Afiliados**. A receita é gerada por meio de:
* **CPA (Cost Per Action) / Comissão:** Ao encontrar o pacote ideal, o usuário é redirecionado para concluir a compra nos parceiros integrados. O Limity recebe uma comissão percentual sobre a venda convertida.
* **CPC (Cost Per Click):** Remuneração baseada no volume de tráfego qualificado redirecionado para as companhias aéreas e redes hoteleiras parceiras.

## 2.4 Principais Funcionalidades (Escopo do MVP)

* **Motor de Busca Reversa:** Algoritmo que recebe `[Orçamento Máximo] + [Data flexível] + [Filtro genérico: ex. Praia, Frio]` e retorna combinações viáveis.
* **Integração de APIs de Viagem:** Consumo de dados em tempo real de provedores para garantir a precisão dos preços sugeridos.
* **Radar Limity:** O usuário salva um orçamento e um desejo, e o sistema monitora em background, notificando via push quando a viagem se torna viável.

## 2.5 Jornada do Usuário

1. **Input Simples:** O usuário digita apenas seu orçamento total e a cidade de origem.
2. **Exploração:** O sistema exibe um mapa ou uma lista com destinos que cabem no bolso dele.
3. **Refinamento:** Aplicação de tags de preferência (ex: "Casal", "Ecoturismo") para filtrar os resultados.
4. **Conversão:** Ao escolher o destino, o app exibe a quebra do valor e fornece o link direto para a compra nos sites parceiros.
