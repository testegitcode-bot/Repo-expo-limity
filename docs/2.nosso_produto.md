# 2. Nosso Produto

## 2.1 Visão do Produto

> "O Limity é um aplicativo de planejamento inteligente para viajantes conscientes do orçamento que permite encontrar o destino ideal baseado exclusivamente no valor que têm disponível, diferentemente das agências online e buscadores tradicionais, pois inverte a lógica da busca: o seu orçamento é o ponto de partida, não a restrição final."
>
> — Visão do Produto, Lean Inception

Enquanto o paradigma atual de plataformas gigantes de turismo (Booking, Decolar, Kayak) exige que o usuário já saiba para onde quer ir para então aplicar filtros de preço, o Limity adota a abordagem **budget-first**: o usuário informa "tenho R$ 2.000 e quero praia" e o sistema responde com os destinos viáveis (voo + hotel) para aquele orçamento naquele momento. Em vez de competir para vender a passagem para um destino que o usuário já escolheu, o Limity ajuda o usuário a descobrir para onde ele consegue ir.

## 2.2 Nosso Produto

| **O que somos (Identidade)** | **O que entregamos (Ação)** |
| --- | --- |
| **É:** Um aplicativo focado no orçamento (Budget-first), B2C, voltado para descoberta e viabilização de turismo. | **Faz:** Filtra destinos por orçamento, cruza dados de voos/hospedagem e sugere pacotes dentro do limite financeiro informado. |
| **Não é:** Uma agência de turismo tradicional, um ERP de gestão financeira pessoal, ou uma plataforma de turismo de luxo. | **Não faz (MVP):** Reserva direta no app (o Limity atua como redirecionador para os parceiros), emissão de vistos, ou roteiros hiper-personalizados dia a dia. |
